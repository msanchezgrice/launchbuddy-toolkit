# First user feedback

Clarify the target person's situation and the biggest current unknown. A problem interview does not require a finished site or a high launch score.

Prepare questions about the last time the problem happened: trigger, workaround, cost, prior attempts, and why the workaround was unsatisfactory. Keep the product pitch until after learning about actual behavior.

If public-source research is requested, return dated primary links and distinguish quotes, observations, and inference. For X research, use native search when available and verify selected posts; do not call ordinary web search native X. Never fabricate prospects, interviews, testimonials, or customer counts. Simulated personas are hypotheses.

Draft a respectful invitation for review. Send only when the user's instruction authorizes messaging and the recipients are clear. Use consented notes to record audience fit, behavior, contradiction, and next decision. End with one test of the biggest uncertainty.
